# Plugins

Vacío a propósito. Cada integración se agrega como su propio proyecto
(`Deck.Plugins.<Nombre>`) recién en su fase del roadmap, no antes — es la regla
de validación incremental (ver `README.md` raíz, principio 4).

Orden previsto: OBS (Fase 3) → Spotify (Fase 4) → Discord (Fase 5) → Twitch
(Fase 6).
